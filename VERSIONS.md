# Version Support

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.7.x   | ❌ |
| < 0.7   | ❌ |

`0.7.x` and anything older is end of life. No more fixes — upgrade.

## History

LTS as a concept started with `0.6.x` — it was the first line to get the LTS label, when `0.7.x` went active.
