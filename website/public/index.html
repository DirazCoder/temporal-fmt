Format and parse Temporal with the tokens you already know.

yyyy-MM-dd in, string out. Bad input throws instead of quietly handing you garbage. Locale-aware, zero dependencies.

$npm install temporal-fmt

100% test coverage 0 dependencies Node 20+

Why this exists

Node 26 shipped Temporal without a string formatter. TC39's answer is to use Intl.DateTimeFormat and let userland handle token-style formatting. Fair enough. But if yyyy-MM-dd is muscle memory, you still want that, so this is that userland.

Examples

What it looks like

Format

import { format } from 'temporal-fmt/format';

const dt = Temporal.PlainDateTime.from('2026-08-04T15:45:30');
format(dt, "MMM d, yyyy 'at' h:mm a");

→ "Aug 4, 2026 at 3:45 PM"

Parse

import { parse } from 'temporal-fmt/parse';

parse('yyyy-MM-dd HH:mm', '2026-08-04 15:45');

→ Temporal.PlainDateTime

It throws

const date = Temporal.PlainDate.from('2026-08-04');

// a date has no hours, so this can't work
format(date, 'HH:mm');

→ an error that tells you what went wrong, not "undefined"

Relative time

import { formatDistance } from 'temporal-fmt';

const today = Temporal.PlainDate.from('2026-08-04');
formatDistance(today, today.add({ days: 2 }), { locale: 'fr-FR' });

→ "dans 2 jours"

Natural language

import { parseRelative } from 'temporal-fmt';

parseRelative('next Tuesday', today);

→ Temporal.PlainDate

Recurrence

import { recurrence, take } from 'temporal-fmt';

const start = Temporal.PlainDate.from('2026-08-04');
const rule = { freq: 'weekly', interval: 1, count: 10 };
take(recurrence(start, rule), 5);

→ the next five occurrences

Features

Small API, deep bench

Strict, not forgiving

A token the input type can't support, input that doesn't match, an ambiguous date: all of it throws a typed error. A lenient mode exists for when you want it.

Locale-aware

Month names, relative time and natural-language parsing work across languages. Register your own vocabulary if yours isn't covered.

No dependencies

Nothing to audit, nothing that breaks on you in a transitive update.

Only ship what you import

Subpath imports and sideEffects: false. Importing just format is roughly 27 KB, against roughly 68 KB for the bare import.

More than format and parse

Durations, intervals, recurrence with RRULE, business calendars and holidays, time zone disambiguation, and a format-string analyzer.

Tested hard

100% coverage, plus fuzz, adversarial and conformance suites. A small thing that tells you the truth about dates should be boring to depend on.
