Providing Temporal

Node 26+: it’s native and picked up automatically.

Polyfill:

import 'temporal-polyfill/global'
import { format } from 'temporal-fmt/format';

Bring your own. Call setTemporal() once, before your first format() or parse(). It wins over a native or global Temporal, and calling it with no argument clears the override. Handy for libraries that don’t want to touch the global namespace.

import { Temporal } from 'temporal-polyfill/full';
import { setTemporal } from 'temporal-fmt';

setTemporal(Temporal);

Only functions that build a value from scratch need this: parse(), parseISO(), resolveZoned() and a few others. Functions that just read fields off an existing value (format(), compare(), add()) never touch the namespace.
