Arithmetic, comparison, rounding, business calendars, holidays, serialization, config, type guards, errors and the analyzer only come from the main temporal-fmt entry for now. sideEffects: false is set, so tree-shaking works.

Tooling extras

analyzeFormat, explainFormat, validateFormat and tokenInfo inspect a format string before you use it. createConfig bundles defaults (locale, zone, rounding and so on). createFormatter adds custom tokens. getAutocompleteData, getHoverDocs and getInlineDiagnostics exist for editor tooling.
