Intervals and recurrence

const iv = interval(start, end, 'closed');   // or open, half-open-start, half-open-end
contains(iv, someDate);
overlaps(ivA, ivB);
formatRange(iv, 'MMM d');

const rule = { freq: 'weekly', interval: 1, count: 10 };
take(recurrence(startDate, rule), 5);
between(startDate, rule, rangeStart, rangeEnd);

Intervals also have intersection, union (null when they can’t combine), mergeIntervals and splitInterval. Where names clash with the date functions, the main entry exports intervalIsBefore, intervalDifference and so on.

Recurrence follows the RFC 5545 RRULE model: freq from secondly to yearly, interval, count, until, weekday and month-day constraints, exclusions. parseRRule and formatRRule read and write RRULE text, and the iterator has next() and previous().
