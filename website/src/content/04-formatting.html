Formatting

format(date, 'MMMM d, yyyy');            // "August 4, 2026"
format(dt, "MMM d, yyyy 'at' h:mm a");   // "Aug 4, 2026 at 3:45 PM"
format(zdt, 'yyyy-MM-dd HH:mm zzz');     // "2026-08-04 15:45 America/New_York"

Wrap literal text in single quotes. For a literal single quote, write ''. Using a token the value can’t support (HH on a PlainDate) throws a descriptive error instead of emitting undefined.

  • format(temporal, formatStr, options?) returns a string.
  • formatToParts(...) returns { type: 'literal' | 'token', value, token? }[], handy for styling individual pieces.
  • compileFormat(formatStr) pre-tokenizes once. Format strings are already LRU-cached (500 entries), so this mostly buys up-front validation: a bad string throws at compile time.
