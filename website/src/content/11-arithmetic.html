Arithmetic, comparison and rounding

add(date, 3, 'days');        // or addDays(date, 3)
difference(a, b, 'hours');   // integer unit boundaries crossed
compare(a, b);               // -1 / 0 / 1
startOf(date, 'month');
getQuarter({ month: 8 }, { startMonth: 10 });   // 4, Apple's fiscal year
  • Arithmetic: add, subtract, difference, plus per-unit wrappers like addMonths and differenceInDays.
  • Comparison: isEqual, isBefore, isAfter, min, max, clamp, isBetween, isToday, isSameDay, isSameWeek, isWeekend and friends.
  • Rounding: round, floor, ceil, truncate.
  • Calendar: daysInMonth, isLeapYear, dayOfYear, weekOfYear, startOf, endOf, getQuarter.
Gregorian only. daysInMonth, daysInYear, isLeapYear, monthsInYear, dayOfYear, weekOfYear and weekYear use Gregorian rules and are wrong on other calendars. For those, read the Temporal object’s own properties (pd.daysInMonth).
