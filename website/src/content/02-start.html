Quick start

import { format } from 'temporal-fmt/format';
import { parse } from 'temporal-fmt/parse';

const date = Temporal.PlainDate.from('2026-08-04');
format(date, 'yyyy-MM-dd');                      // "2026-08-04"

parse('yyyy-MM-dd HH:mm', '2026-08-04 15:45');   // Temporal.PlainDateTime

format(temporal, formatStr) in, parse(formatStr, input) out. Same shape as date-fns or Day.js.

Import from the subpaths, not the bare package. The package is big on npm (locales, recurrence, calendars, an analyzer), but a bundler only ships what you call. Measured with esbuild, format alone is about 27KB via the subpath and about 68KB from the bare entry.
