Testing and contributing

3,000+ tests across test/, vitest/ and a consumer suite. The smoke runner packs and installs the package, checks every public subpath in CJS and ESM, and runs type probes under both bundler and nodenext resolution. CI covers Node 20, 22, 24 and 26 on Ubuntu, Windows and macOS, plus the Vitest suite and a Playwright suite in Chromium, Firefox and WebKit.

Both the classic Node node:test suite (npm run test:coverage, c8 against dist/) and the full Vitest suite (npm run test:unit -- --coverage, V8 against src/) enforce 100% statement, branch, function and line coverage.

npm test               # classic node:test suite
npm run test:unit      # vitest
npm run test:smoke     # packed-package smoke suite
npm run test:browser   # Playwright against dist/
npm run test:all       # all checks, including browser tests
npm run test:all -- --no-browser  # all checks except browser tests
npm run bench          # tinybench suites

Install the Playwright browsers before running browser tests with npx playwright install; Linux also needs npx playwright install-deps.

A portable fixtures.json conformance set checks DST, leap years, offsets and calendar limits against cases from outside this library. Hacking on it: git clone, npm install, npm run build, npm run test:all. The build needs TypeScript 7.0.2+, and .d.ts files come from a separate tsc pass because tsup’s dts step isn’t stable on 7.x.
