Testing and contributing

Tests span test/, vitest/, the packed-package smoke suite, and a separate conformance suite. The smoke runner packs and installs the package, checks every public subpath in CJS and ESM, and runs type probes under both bundler and nodenext resolution. CI covers Node 20, 22, 24 and 26 on Ubuntu, Windows and macOS, plus the Vitest suite and Playwright in Chromium, Firefox and WebKit.

Both the classic Node node:test suite (npm run test:coverage, c8 against dist/) and the full Vitest suite (npm run test:unit -- --coverage, V8 against src/) enforce 100% statement, branch, function and line coverage.

npm test               # classic node:test suite
npm run test:conformance # separate reference-vector suite
npm run test:unit      # vitest
npm run test:smoke     # packed-package smoke suite
npm run test:browser   # Playwright against dist/
npm run test:all       # all checks, including browser tests
npm run test:all -- --no-browser  # all checks except browser tests
npm run bench          # tinybench suites

Install the Playwright browsers before running browser tests with npx playwright install; Linux also needs npx playwright install-deps.

npm test does not include conformance. Run npm run test:conformance for the portable fixtures and curated vectors translated from relevant Temporal/Intl, CLDR, tzdb, recurrence, token, relative-date and wire-format reference domains. These are not wholesale upstream suites and do not claim complete standards compliance; see conformance/README.md for attribution and limits. Hacking on the project: git clone, npm install, npm run build, npm run test:all. The build needs TypeScript 7.0.2+, and .d.ts files come from a separate tsc pass because tsup’s dts step isn’t stable on 7.x. Licensed Apache 2.0.

The ESLint plugin and jscodeshift codemod are deprecated and archived. The last published versions still work.
