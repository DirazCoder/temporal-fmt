Natural-language dates

parseRelative(input, referenceDate, options?) turns phrases into a PlainDate. English by default, plus es, fr and de.

const today = Temporal.PlainDate.from('2026-08-04');   // a Tuesday
parseRelative('next Tuesday', today)    // 2026-08-11
parseRelative('last Friday', today)     // 2026-07-31
parseRelative('in 3 days', today)       // 2026-08-07
parseRelative('March 5th', today)       // 2027-03-05
parseRelative('mañana', today, { locale: 'es-ES' })   // 2026-08-05

It handles weekday references, today/tomorrow/yesterday, “in 3 days” and “2 weeks ago”, and month-day with no year. The calls it makes on ambiguous input:

  • “next Tuesday” on a Tuesday is 7 days out. Use “this Tuesday” for the same week.
  • “March 5th” with no year means the next occurrence, so a past date rolls to next year.
  • A bare “5 days” with no “in” or “ago” throws, same strict contract as parse().

Diacritics are stripped before matching, so miercoles works. { fuzzy: true } fixes typos like tommorow using edit distance 2. It’s English-only, and pairing it with another locale throws instead of silently skipping the correction. Numbers are never corrected. Add your own language with registerRelativeGrammar.
